## 验收中修复的问题

1. 新对话的 URL 曾保留旧 conversationId，刷新可能回到旧实验；现已同步对话 ID，并尊重显式指定的对话。
2. 实验状态未变时报告缓存没有随新观测更新；现将观测时间纳入刷新判断。
3. 连接恢复后旧错误残留；现同步清除对应的连接错误。
4. 窄窗口下“经典模式”悬浮按钮覆盖发送按钮；已移至顶部并补充可访问名称。
5. 编辑已确认的表单时旧成功提示仍存在；现在未重新确认的表单不显示旧确认提示。
6. 模型输出推理文本、预算耗尽后截断；预设实验只接收完整最终内容，结构化解读只读取 explanation 字段，并使用当前模型服务支持的推理预算。解析失败保留真实报告和原草稿。
7. 后台仿真循环异常可能没有通知实验控制服务，页面一直显示运行中；现发送 runtime_error，控制服务按运行时 ID 将当前轮标为失败，忽略旧运行的错误。

为保留完整队列，正常实验进程在后台异常回传修复期间未中断；该修复只改变异常分支，已通过加载新代码的隔离真实服务注入写盘异常复验。早于普通观测接收就绪的当前运行错误、以及旧运行错误的忽略逻辑由回归测试覆盖。
