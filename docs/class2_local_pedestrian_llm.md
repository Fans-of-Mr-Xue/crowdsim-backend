# 第二类活动行人局部决策实验

2026-11-14已接入新版第二类正式异步推演流程。执行记录包含 `class2_demo.background_count`（包括0）时，在初始化阶段创建控制器；旧第二类省略该字段，不启用。第一类及背景行人的控制逻辑保持原样。

## 控制循环

`crowdsim/scenarios/class2_local_pedestrian.py` 提供提示词、`observe(person_id)` 局部输入和 `decide_round()`。`SimulationRuntime.tick_async()` 在通用规则执行前调用控制器，仅选择现有人流布局中全部非背景行人，并阻止通用自主规则重复覆盖他们的动作。每10个仿真秒触发一轮，对每人分别调用服务器GLM，最多4个请求并发；等待整轮结束再推进SUMO。此同步边界避免旧快照结果覆盖新位置，尚不承诺实时播放性能。已到达、处于停留保留阶段或SUMO内部路口边的行人跳过本轮。

每轮耗时和精简的逐人决策写入原运行的 `commands.jsonl`（`class2_local_llm_round`），性能探针记录 `class2_local_llm`。初始化信息提供模型、控制人数、并发数和单请求超时。新版前端按这份信息延长暂停/关闭等操作的确认等待时间，避免现有20秒上限将模型等待误报为断连；不修改页面布局或旧版等待时间。后台快速基线预览仍使用原有同步规则步进 `tick()`，不调用GLM，也不表示LLM行为预测。

模型只接收自身属性、当前速度/朝向、受阻时间、最终目的地方向、感知半径内所有行人的相对位置/速度/朝向、裁剪后的道路片段、局部可走中间点、已收到且有效的消息以及上一次自身决策。附近行人的身份、目标、心理状态和远处实时人群数据不进入输入。感知采用跨路段距离半径，当前没有建筑遮挡模型，不能解释为严格视线可见性。

局部候选由现有位置寻路器校验：中间点在感知半径内，步行到中间点的距离也不超过半径，并且能继续前往原终点。完整接续路线仅保留在执行端；不向模型展示全程路网、路线成本或远处拥堵。排除需要在道路中段掉头、重复绕行和与当前路线相同的候选，最多提供3个。后续仍由SUMO完成具体步行和避让。

动作仅有：继续、按配置速度60%减速（最多10秒）、等待2秒、选择局部路径候选。选择候选复用 `BehaviorPlan` / `PlanExecutor` 的 `preserve_future_stages`，保留原目标道路、精确终点及到达后的停留阶段。失败回退到原路线；过期快照结果丢弃；无法恢复的SUMO行程执行失败仍按现有运行错误处理。通用个体决策在该独立实验内不再覆盖活动行人的决定。

## 后台复现

使用已建立的服务器模型连接，不启动前后端或模型服务：

```bash
/opt/miniconda3/envs/sumo/bin/python scripts/check_class2_local_llm.py \
  --requirement runs/requirements/req-b192c617ee6272173fcf62dbef592296.json \
  --seconds 100 --output docs/validation/class2_local_llm_integrated_20261114.json
```

脚本只读已冻结的执行记录和人工社会模型，在临时目录启动独立SUMO，使用正式运行自动创建的控制器和 `tick_async()`，不再手动挂载控制器；不会修改「测试事中18」会话、快照或网页正在使用的运行。输出汇总JSON及逐次输入、选择和执行结果JSONL，检查人数、身份、终点、感知半径边界，以及背景行人到达停留5秒后的随机出发。记录每一步实际耗时、模型轮耗时及超过1秒的停顿。GLM复用现有请求传输，并采用项目中服务器GLM连接器已有的 `enable_thinking=false`、`reasoning_budget_tokens=0`，避免思考内容耗尽短决策预算。

本实验验证局部信息到模型决策再到SUMO执行的链路。没有真实行人轨迹对照，因此不据此断言比规则模型更符合真实行为。

## 独立原型验证记录（2026-11-13）

- 代码测试：局部输入不受远处人员变化影响、跨路段邻居可感知、输入不包含他人私有目标、非法动作被拒绝、模型失败保留路线、过期结果不执行；连同既有位置寻路和调度测试，共13项通过。
- 独立执行检查使用固定测试决策（不是GLM输出），真实SUMO运行80秒：20次减速、20次等待、22次改道和72次继续均成功执行；60次等待速度检查、380次减速上限检查通过，人数、身份和终点保持。见[动作执行记录](validation/class2_local_action_execution.json)。
- 真实GLM测试的汇总见[模型运行记录](validation/class2_local_llm.json)，逐次输入和执行结果见同目录 `class2_local_llm.decisions.jsonl`。失败次数单列，不能将回退继续计为模型成功决策。

2026-11-13实测使用测试事中18的313名背景行人和20名活动行人，真实SUMO推进180秒，共280次决策请求，243次有效GLM输出（235次继续、4次等待、4次减速）。37次回退由8次读超时、4次读取错误和25次连接错误构成；测试结束后原GLM端点再次检查可达。所有280次计划执行成功，未改变人数、身份或原终点。20名活动行人均已移动，1人到达并停留，平均到终点的直线距离从104.13米降至13.67米；没有将“接近终点”计为到达。

本场景给模型提供过15次含局部替代路径的输入，但GLM没有选择改道；因此实际GLM改道选择能力尚未在这一自然场景中得到验证。改道执行能力由上述独立固定决策测试覆盖。全程耗时约585秒，其中决策轮约543秒，当前同步原型不适合直接承诺实时播放。控制台另有8条背景行人碰撞警告，7条位于此前已记录待处理的孤立短步道；没有人员丢失，本次未修改该路网问题。
