# 2026-11-20 事后算法对接复核

## 已复现并修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 实际参照为 CF-01 等非 F-00 时，子集 normalize 重排 world_ref | 条件对比的引用可能指向另一个实验组或种子 | 计算仍用源 `_contrasts`，传入全批次的 canonical world 对象，全部引用与 worldBindings 一致 |
| 跨世界汇总概率使用证据时间的平均值 | 平均时刻可能早于某个参与世界已使用的证据 | 概率均值不变，展示时刻取最晚证据时间，并保留最早时间 |
| 不同策略中同一种子重复计入独立样本 | 夸大独立样本量 | 世界数单列；独立样本数去重 seed，并返回各组计数及配对说明 |
| 分析输入与汇总曲线遗漏 peakDensity | 全域低平均密度可能遮蔽局部高密度；“密度峰值”曲线实际画全域均值 | 输入分开保留 local_peak_density/density；服务端汇总保留 peakDensity；现有峰值图按局部峰值绑定 |

未修改源算法的计算实现；变化发生在适配输入、引用地址、统计元数据与图表字段绑定。源文件 hash 检查继续保留。

## 用户已明确

1. 主拥堵指标采用最拥挤网格密度。新设计默认主要终点 peak_density；旧设计和旧批次主要终点不改写。
2. 机制一个回合对应一次引导后的群体响应阶段。
3. 预测保留源算法的首次明确终局，不预测窗口末四态。

旧四态定义与源 PROMPT（首次未来明确结局）冲突，不能因为 JSON 概率校验通过就视为语义正确。生产已停止发出此错误定义的预测，明确返回 terminal_definition_required；数值比较、候选路径与原始证据仍可运行。测试显式注入测试终局类别，不能将测试概率当成实际终局预测。

## 尚需定义或验收

| 边界 | 当前事实及所需决定 |
| --- | --- |
| 终局条件 | 高密风险和恢复稳定各自的密度/速度条件、持续时间及互斥关系；未达终局按右删失，不硬塞成结局概率类别。用户曾提出3.8人/m²；此次仅确认主指标，未确定3.8阈值持续时间或新增事故判定。 |
| 群体响应阶段 | 阶段开始以实际发布还是实际送达计时；何时结束；多次引导重叠如何分配；F-00如何按同一时钟配对。推荐分开记录发布→送达、送达→决策、执行→实际移动，避免将执行回执直接当成运动落实。 |
| 群体门控输入 | 目前只有个体容忍、入口换路收益/冷却等参数，没有已定义的群体净推力权重与同量纲阈值。需确定每个动因的含义、来源、归一化、门槛以及对应宏观增量；不能用相关系数或提及率代替。 |
| 时间粒度 | 当前八等分仅作有界描述摘要，不能表达秒级响应滞后，也不能代替已确认的引导响应回合。实际阶段边界明确后再对齐输入。 |
| 页面绑定 | 原机制图仍采用旧统计占位节点，真实微宏观图仅在工件中，候选路径进入结论文字；四态概率图也未成为首次终局图。待终局与回合映射确定后，先说明所需字段/标签变化，再处理，不擅自改 Vue 页面设计。 |
| 模型验收与补算 | 本轮未声明真实模型质量通过；端点此前超时。现有批次模型分析部分失败后尚无专用“仅重算分析”入口，建议后续复用已有 runs 补算，避免重跑 SUMO；本轮没有擅自新增入口。 |
