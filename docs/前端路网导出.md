# 将 SUMO 路网导出给独立前端

`scripts/export_frontend_road_network.py` 从当前 SUMO `.net.xml` 生成 `road_network.json`。脚本只处理文件，不启动 SUMO，也不连接前端。默认输入为 `scenarios/shanghai_bund/bund.net.xml`，默认输出为 `outputs/frontend/road_network.json`；`outputs/` 是 Git 忽略的生成目录。

在后端目录中执行：

```sh
# 首次使用时，在运行导出脚本的 Python 环境中安装可选几何依赖。
python -m pip install -r requirements-road-export.txt

python scripts/export_frontend_road_network.py
```

也可以指定其他路网或输出位置：

```sh
python scripts/export_frontend_road_network.py \
  --network scenarios/shanghai_bund/bund.net.xml \
  --output outputs/frontend/road_network.json
```

将生成的 **整个 `road_network.json` 文件**手动复制到前端的 `public/static/crowd_sim/road_network.json`，覆盖同名文件。当前本机前端的路径是：

```text
/Users/omega/Documents/CrowdSim/frontend/public/static/crowd_sim/road_network.json
```

前后端部署在不同机器时，通过现有文件传输方式复制即可。前端已接入此文件，今后每次路网修改只需重新导出、复制、刷新页面；不需要再次修改前端代码。生产部署时还应将新文件发布到提供 `/static/crowd_sim/road_network.json` 的静态资源服务。

## 导出内容

- `roadLines`：合并后的道路和路口边界，包括外轮廓及内部空洞，全部为闭合折线。
- `roadSegments`：普通道路及其车道中心线、宽度、长度和连接路口 ID，用于追溯具体道路。
- `walkingAreas`：行人路口的实际形状及 SUMO 宽度属性，保留之前拓宽过的路口信息。
- `junctions`：普通路口的位置和形状，不包括车辆转弯用的内部节点。
- `source`：源文件名称、SHA-256、SUMO 路网版本、投影及平移参数。
- `counts`、`bounds`：导出统计和 WGS84 经纬度范围。

脚本先在 SUMO 的米制坐标中按每条车道的 `width / 2` 构造道路区域，再与实际路口多边形合并。`walkingarea` 已经是区域，直接使用其形状，不再按宽度重复扩张。车辆内部转弯连接线由路口区域覆盖；人行横道单独纳入道路区域。

坐标转换使用源文件 `<location>` 的 `projParameter` 和 `netOffset`，输出明确标记为 **WGS84、`[经度, 纬度]`**。前端现有的 WGS84 → GCJ02 转换继续在绘制阶段执行。没有投影信息的输入会报错，避免将米制坐标当成经纬度。

旧 SUMO 文件中的部分区域有自交或零面积几何。导出器修复无效的面，并在 `repairedSurfaces` 中统计；无法形成面的记录计入 `emptySurfaces`。只有两个顶点的行人路口仍保留在 `walkingAreas`，计入 `degenerateWalkingAreas`，不为其虚构多边形。相关位置使用源文件中的相邻车道和路口面。

## 前端读取方式

`CrowdSim3DViz.vue` 先加载 `simulation_data.js`，再加载独立路网并替换 `window.simulationData.roadLines`。场景、轨迹、地图中心等其他基础数据保持原值；雨水和积水定位也会读取替换后的共享道路数组。独立的 `crowd_sim_viz.html` 预览页同步读取同一个导出文件。

前端读取新文件时使用 `cache: 'no-store'`，每次组件重新挂载都会重新读取。已打开的地图仍需刷新页面重新绘制。文件缺失或格式错误时显示路网加载错误。

## 代码级检查

后端检查（需要先安装可选导出依赖）：

```sh
python -m unittest tests.test_frontend_road_export -v
```

前端目录中的检查：

```sh
node --test tests/crowdSimRoadNetwork.test.mjs
```

检查包括道路宽度、路口区域、源文件不变、可重复导出、投影、M3/H2 几何、全部行人路口宽度，以及前端更新与错误处理；不会启动仿真。
