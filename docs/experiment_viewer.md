# 实验指标查看器

查看器读取后端 `runs/<run_id>/` 保存的观测记录，导出独立 HTML。
它不启动 SUMO、不连接前端、不改写原始实验、不修改心理或运动模型。
新实验完成或暂停后，重新执行导出命令即可更新实验列表和数据。

## 使用

在后端根目录、当前终端的 Python 环境已准备好时执行：

```bash
./viewer.sh
```

脚本生成 `outputs/experiment_viewer/index.html`，随后自动请求默认浏览器打开。
`viewer.sh` 和 `run.sh` 均不执行环境激活、环境切换或任何 conda 操作。
它们优先使用当前 PATH 中的 `python`，不存在时使用 `python3`；也可通过
`CROWDSIM_PYTHON` 指定解释器，例如 `CROWDSIM_PYTHON=/path/to/python ./viewer.sh`。
脚本会先切换到后端根目录，相对输入/输出路径均以该目录为基准。
生成失败时不会打开旧页面；`./viewer.sh --help` 仅显示参数说明。

HTML 内嵌数据、样式和脚本，不需要网络、CDN、WebSocket 或 HTTP 服务。
同目录的 `data.json` 是对应的轻量查看器数据；HTML 单独复制到其他电脑也能打开。
页面优先选择与已同步预设范围一致的实验，同一范围优先选择过程帧最多的实验。
旧范围的实验仍可通过下拉框查看。

导出参数会原样传给 Python 导出脚本，包括自定义输出目录：

```bash
# 只导出指定实验，可重复使用 --run
./viewer.sh --run run-xxxxxxxx

# 自定义输入/输出目录
./viewer.sh --runs-root runs --output outputs/experiment_viewer

# 额外导出每轮十项指标的静态 PNG
./viewer.sh --png

# 大实验减少空间图帧数；全局曲线和 B3 面积加权均值保留全部帧
./viewer.sh --max-map-frames 600

# 使用另外一份范围对照快照（仅对照，不改变实验数据）
./viewer.sh --scope-reference-file config/viewer_scope_references.json
```

需要只生成文件、不打开浏览器时，直接运行 `python scripts/build_experiment_viewer.py`。

基础查看器仅用 Python 标准库。`--png` 另需 `matplotlib`，可用
`python -m pip install -r requirements-viewer.txt` 安装；本项目当前 SUMO 环境已可导出。
静态图写入 `outputs/experiment_viewer/png/<run_id>/A1.png` 至 `C2.png`，
空间图使用最后一个可展示快照并标注时间，未完成指标生成缺失说明而非虚构终值。
存在兼容的新旧范围差异时，另生成 `scope_comparison.png`。

## 外滩范围调整

已核对前端 2026-10-10 调整的南京东路—外滩预设：边界由 51 点改为 16 点，
面积由约 25,134.81 m² 增至 30,161.65 m²。按当前 20 m 均匀网格计算，
旧范围有 107 个片区，新范围有 117 个片区。新边界覆盖当前场景的 31 条道路车道、
23 个 walking area 和 24 个路口。

`config/viewer_scope_references.json` 保存此次核对后的经纬度边界、米制边界和投影，
仅供查看器对照。脚本不依赖本机的前端目录，这个文件不控制仿真的统计区域。
页面显示本轮范围与对照预设各自的版本编号、面积和边界点数；版本按边界生成，
不把起始点或顺逆时针顺序变化当成新版本，也不以面积相同判定范围相同。
展开“查看新旧范围边界对照”可查看边界图。空间指标上的实线是本轮实际统计边界，
橙色虚线是已同步预设边界，可关闭；投影不兼容时不叠加虚线。

已有实验继续使用其原始面积、网格和全部指标。查看器不会扩大旧范围、补入旧范围外
人员或按新面积重算密度。CSV 和 PNG 导出也标明本轮范围版本及实际面积。
新的实验自动读取自己保存的区域和网格，无需把片区数量写进脚本。
**需要重新选择调整后的预设、提交一份新需求，再初始化实验**，才能采集新范围的数据。
已保存的需求和继续运行的旧实验保留原边界；仅修改前端预设不会更新它们。
以后再次调整预设时，可以同步更新对照快照；即使对照快照未同步，实验自身的区域和
指标仍按其保存值正确展示。

## 页面操作

- 顶部选择场景和实验，显示完整 `run_id`、`requirement_id`、统计范围和热点。
- 左侧切换 A1–A5、B1–B3、C1、C2。D1/D2 当前没有决策产物，注明暂未实现。
- 时间滑块对齐本轮已提交快照；播放是离线逐帧回放，不代表 SUMO 运行倍速。
- A2/A4 点击片区或通过编号下拉框选取，查看人数、实际面积和时间曲线。
- A5 点击边界查看 A/B 片区和方向，可切换有符号差与绝对差。
- B3 三张地图使用一致颜色范围，同步显示三组绝对密度差。
- 空间图可用滚轮以鼠标位置缩放；按钮可放大、缩小、还原视野。
- C1/C2 可切换人数与比例。状态转换表排除首次建立标签，区域出入单列。
- “指标 CSV” 导出当前指标数据及本轮范围版本、面积；局部指标导出保留的全部空间帧，而非单帧。
- “图表 PNG” 导出当前指标的可见图表；“导出查看器数据”保存完整查看器 JSON。
- 下面的数据说明展示旧版本限制、缺失/重复/未提交数据和路网版本情况。

空间图默认保留最多约 1200 帧，始末和事件/策略/完成基线优先保留，
很小的自定义上限可能因保留这些时刻而略超出。地图标注实际使用的快照时间，
下方局部曲线和局部 CSV 使用同一组保留帧；原始 CSV 没有删减。
本轮各空间指标的图例范围固定，跨场景不共用区域几何或面积。

## 指标与口径

| 指标 | 展示 | 主要数据 |
| --- | --- | --- |
| A1 全局密度 | 区域密度曲线；区域内/外/全路网人数 | `observation_global.csv` |
| A2 局部密度 | 固定片区密度图、选中片区曲线 | `observation_cells.csv`、保存的片区几何 |
| A3 全局速度 | 含停留平均速度、运动人员平均速度及样本数 | `observation_global.csv` |
| A4 局部速度 | 片区平均速度图、选中片区曲线 | `observation_cells.csv` |
| A5 边界密度差 | A − B 发散色图或绝对差；边界曲线 | `observation_boundaries.csv`、边界编号与方向 |
| B1 疏散时间 | 最终时长、过程时长、t0/ta/te 时点和目标人口进度 | `evacuation_state.json`、`evacuation_progress.jsonl` |
| B2 疏散效率 | 最终效率、策略时/结束时密度与过程 | 同上及全局观测 |
| B3 人群密度差 | 初始—运行时、运行时—结束、初始—结束三图；面积加权局部绝对差曲线 | 生命周期基线、完整片区快照 |
| C1 行为变化 | 状态构成、实际转换次数/矩阵、区域出入、拥挤附加标签 | 全局观测、`state_transitions.jsonl` |
| C2 心理变化 | 状态构成、压力等模型均值、实际心理转换次数/矩阵 | 同上 |

疏散口径与 [疏散观测说明](evacuation_observations.md) 一致：
t0 为首次运行，ta 为首次成功应用有效疏散策略，te 为本轮所有目标行人正常完成
SUMO 行程。`observation_result.status=complete` 只是记录结束，不能代替 te。
终值必须有已提交的完成快照和无异常的正常到达人口账本。
B1 = te − ta；B2 = (ρa − ρe) / (te − ta)，零时长的效率为空。
B3 先逐片区取绝对差，再按实际面积加权；不能用全局平均密度差替代。

## 数据有效性与旧记录

`observation_samples.jsonl` 是快照提交边界。读取器忽略未提交编号或时间不匹配的行，
合并重复快照/片区/边界行，并检查快照索引的行数。缺失值保持 `null`，不当成零。
零密度表示有面积、无人的片区；无人平均速度为空；没有区域外采样的外边界为空。
转换事件数不符合提交索引的帧不进入转换曲线或累计矩阵。
无效位置帧的 B3 不补零；A1/A2 仍是实际可定位人员的观测，页面作出提示。
不可读取的实验显示在跳过列表；如果一份有效记录也没有，命令明确报错。

旧版 v1 没有疏散生命周期。仅当 `commands.jsonl` 中存在首次成功 `start`，
且时间能对应完整观测快照时，补算 B3 初始—运行时差，并标为“旧记录补算”。
后续恢复运行的 `start` 不重置基线。不还原旧 B1/B2，也不把最后一帧当作结束分布。
只初始化但未运行的记录没有事件初始基线。

地图使用 `observation_geometry.json` 保存的 SUMO 米制区域、片区和边界。
只有当前 SUMO 路网文件的 SHA-256 与实验保存值一致时，才叠加道路。
路网已修改或文件不可用时保留冻结的观测几何，明确说明缺少匹配底图。
不会将前端地图坐标误差或后来新增道路带入旧实验。

查看器不读取体积很大的 `trajectory.csv`，也不公开服务或上传数据。
正在运行的实验仅展示导出时已提交的记录；生命周期检查点可能稍早于末次快照，
因此正式验收建议在暂停或完成后导出。

## 检验

```bash
python -m pytest -q tests/test_experiment_viewer.py
```

测试覆盖完整提交过滤、重复行、空值/零值、时间匹配、首次标签排除、转换缺失，
旧版基线补算、新版三个疏散指标、异常人口/未提交结束、无效位置、零时长，
以及输出目录保护和 HTML 数据转义。范围测试检查旧指标及原始文件保持不变、
边界版本识别、坐标偏移/投影不兼容，以及通过实际记录器写出新外滩范围的 117 个片区
并由查看器读回。另对实际记录检查浏览器切换、时间回放、地图选取及 CSV/PNG/JSON 导出；
没有启动新的仿真实验。
