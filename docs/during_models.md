# 事中 GLM 与独立启动

事中对话、工具链、策略生成和总览文字生成使用 GLM-5.3-Flash，经事中网关 `/api/crowdSim/during/models/GLM-5.3-Flash/chat/completions` 转发至本机 `8800/v1`。事中菜单仅提供 GLM；浏览器保存的旧事中模型选择会回落到 GLM，旧消息重试也使用 GLM，历史产物中的模型标识保留。

事中停电备用模型的环境变量、Key 和代理配置已移除。原有工具协议和参数校验继续使用。共享模型配置、事前和事后的模型选择及独立行人决策 Skill 不受此次清理影响。

通常在后端根目录使用 `./run.sh`，由统一入口管理模型和数据库连接。事中独立入口仍可使用：

```sh
conda activate sumo
./run_during.sh --check
./run_during.sh
```

独立入口启动本机8765仿真、8766实验控制、8767对话存储、8768事中模型网关，不连接 MongoDB、不建立 SSH 隧道、不构造事后应用。使用 GLM 前需保持本机 `127.0.0.1:8800` 至服务器模型的连接可用。`--check` 只检查本地依赖和场景，不验证远程模型连接。

前端仍单独运行 `npm run dev`。代码或后端配置变更后，应重新启动相应本地服务以加载变更。
