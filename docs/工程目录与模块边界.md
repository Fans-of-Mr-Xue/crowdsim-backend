# 工程目录与模块边界

业务实现统一位于 `crowdsim` Python 包，根目录不再平铺实现模块。

| 目录 | 职责 | 主要文件 |
|---|---|---|
| `crowdsim/domain` | 不依赖运行流程的数据合同、画像抽样和真实同行关系 | `crowdsim_models.py`、`population_profiles.py`、`group_manager.py` |
| `crowdsim/core` | 唯一仿真生命周期、人口账本、同步状态更新和边界命令 | `simulation_runtime.py`、`population_manager.py`、`state_updater.py`、`runtime_commands.py` |
| `crowdsim/environment` | 只读局部观察、事件/信息/危险、干预和POI活动 | `crowd_environment.py`、`event_manager.py`、`information_model.py`、`hazard_model.py`、`poi_catalog.py` |
| `crowdsim/decision` | 计划生成、调度、合法路线和TraCI计划执行 | `agent_decision.py`、`decision_scheduler.py`、`route_provider.py`、`plan_executor.py`、`llm_gateway.py` |
| `crowdsim/infrastructure` | 外部技术适配和输出，不包含行为政策 | `sumo_adapter.py`、`network_adapter.py`、`websocket_server.py`、`frame_serializer.py`、`metrics.py`、`experiment_recorder.py` |

依赖方向原则：`domain` 提供合同；`environment` 和 `decision` 使用合同；`infrastructure` 连接 SUMO/网络/存储；`core` 在时间边界编排这些模块。外部程序只通过根启动入口、`SimulationRuntime` 或 WebSocket 协议进入，不直接调用 TraCI 全局对象。

正式实验场景位于 `scenarios/shanghai_bund`。`tests/scenarios` 中的小型 SUMO 路网只用于回归测试，不作为正式研究实验结果。
