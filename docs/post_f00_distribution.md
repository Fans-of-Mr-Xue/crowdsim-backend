# 同场景 F00 配置与分布初始化

2026-11-10。仅修改事后后端；事中实现、前端、其他阶段和进程退出清理不变。

从原有 `/datasets` 导入 MongoDB 事中来源时，后端按 `metadata.sourceBinding` 校验归档版本、文件哈希及访问权限，重新读取完整逐格目标。执行模式为 `spatial-distribution/2.0`。旧的全局摘要数据集保留，执行时明确要求重新导入，不能重新标记为完整空间输入。

## 配置与生成

- 来源人数、时窗和采样频率以实际归档为准，不使用预设的 700 人、1800 秒。
- 复用事中研究边界和 `ObservationCollector` 的网格 ID、裁剪面积、原点、归属及边界带规则；逐格核对归档面积、时间覆盖、密度和人数守恒。几何不匹配时拒绝运行。
- SUMO 的步长、striping 参数及遥测频率从已绑定配置读取。当前同场景归档为 20 米网格、0.5 秒采样。FCD 时刻换算为完成模拟步的时刻，保留 0.5 秒首帧和 600 秒末帧。
- 初始人数按首帧每格人数生成。可用首帧轨迹提供道路与位置支持；轨迹缺失时按原格内可行走道路线长采样，不要求原个体、原路线或原随机种子。网格边缘在同一道路内预留条带宽度，避免插入跨格。
- 个体属性复用 `PopulationProfileSampler` 和当前事中人口分布。类别配额按实际人数分配，速度等连续属性按分布采样，热点目标位置按事中 viewing-zone 权重分层采样，活动释放时间使用事中配置的活动结束时间及延迟分布。F00/CF 共用输入与种子，不按后续事实曲线强行增减人员。
- 不自动加入原来的 360 秒开门、30 秒延迟和 0.4 遵从率。归档未记录的事实控制标为未知；本次采用“无额外控制”的显式模型假设。当前环境资源哈希随输入冻结；历史配置未独立归档，不宣称历史资源逐字节一致。

## 存储、展示和测量

完整空间目标经压缩、带哈希及工作区绑定存入 GridFS，恢复时核验完整性和解压大小。不是把 96,000 条数据塞进 metadata 或单个 MongoDB 文档。原始归档和旧数据不覆盖。

默认 `/datasets/{id}/timeline` 仍返回原全局展示摘要，兼容现有页面恢复与图表。`observationCount` 为展示条数，`spatialObservationCount` 为完整目标条数。`/reconstruction`、执行器和测量器使用全部空间目标；`/timeline?view=spatial` 可分页读取完整目标。

全局密度为研究边界内人数/原研究区域面积，网格峰值密度单列。空网格保留人数0、密度0、速度null。逐格测量和残差按帧分块归档，结果文档只保存 MAE、RMSE、最大误差和比较条数。边界外未观测保留无定义状态。计划停留依据实际 hold/release 事件排除在阻塞判定之外。

`ready` 仅表示输入可执行。运行成功仍返回 `calibrated=false`；当前没有配置拟合验收阈值，也没有完成历史行为模型的拟合。后续应根据实际逐格残差校准路径选择、行为及未知控制，再冻结通过验收的 F00。
