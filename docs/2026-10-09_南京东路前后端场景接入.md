# 南京东路外滩路口：需求到 SUMO 场景的接入

## 运行方式

更新后端后重启服务；前端刷新页面。普通启动即可接受两个预设：

```bash
python crowdsim_overlay_server.py --host 127.0.0.1 --port 8765
```

在需求界定选择“南京东路外滩路口”、配置人数/画像/观测并提交；到决策推演连接后端，
等待初始化完成，然后开始仿真。切换另一份需求前先用前端“重置”断开。
已有南京东路需求记录也可使用，加载时会刷新能力声明，不改写历史需求文件。

## 实现

- 需求能力增加 `east-nanjing-road`。客户端仍只发送已提交的 `requirement_id`，后端按不可变记录选场景，客户端不能指定任意配置文件。
- 普通服务注入需求运行工厂，初始化前将纪念塔绑定到 hotspot，将南京东路绑定到 `east_nanjing.sumocfg`。自定义配置保持显式网络。活动运行期间不能换需求，相同握手不重建运行。
- 外滩预设使用 `generated_hotspot` 和独立的 `scenarios/east_nanjing_road/crowd_hotspots.json`，热点为陈毅广场。`HotspotDemandSpec` 生成本轮人数的聚集及离场路线，不重复使用 68 人演示；起点按现有 31 条道路长度分配，全部 depart=0。画像、观测、记录与现有运行流程共用。
- 初始人群在 READY 阶段显示，真实初始时间为 0.5 秒。重置保留已提交的人数、画像和地点；每轮生成单独的运行目录、需求文件和报告。
- 前端按需求地点选择道路导出、地图中心和局部场景名称；开始运行后的事件记录与决策区域也绑定实际地点和中心。南京东路不播放纪念塔的离线演示轨迹。初始化校验需求、地点、聚集模式和热点 ID；道路加载核对 SUMO 网络 SHA-256，旧组件的迟到请求不能覆盖新路网。
- SUMO adapter 在原生 macOS bundle 未设置 PROJ 路径时查找自身安装中的数据库，避免行人地理坐标偏移；已设置的环境变量保持优先。

本次没有修改两份 SUMO 路网几何或预设区域。南京东路仍为 31 条道路、24 个节点，
23 个 walking-area；宽度保留上一轮至少 4 米、四岔路口至少 5 米及更宽的历史配置。

## 陈毅广场行为

- 聚集目标及测量道路为 R25b、R29、R26b、R30；按可用步行面积分配目标位置。
- 进入通道为 R13、R18、R25a、R26a、R25c、R26c。
- 刷新、到达后的原地停留、动态择路和释放机制均复用纪念塔。活动窗口 600～800 秒，
  各访客在 800～890 秒间按分配时刻释放；不强制到达时间，也不采用固定停留时长。
- 离场目的地在 R01、R02、R03、R22、R31 中均匀分配，继续预先安排的第二段 walk。
- 初始化返回热点名称与锚点，前端将聚集事件定位至陈毅广场，保留原需求区域边界与地图中心。
- 活动类别仍为需求元数据；当前预设运行的是上述聚集行为，不按类别自动更换行人活动计划。
- 需求人数是本轮初始访客数。已保存需求可取 1～10000，未绑定需求的协议实验允许 0 人；
  空场仍声明当前配置热点，重置保留需求、人数和热点配置。

## 本轮代码级验证

仅执行静态检查、离线路线生成、适配器替身单元测试及前端生产构建；不启动 SUMO、
WebSocket 或 TraCI，不包含真实运动过程及聚集容量验证。

`tests.test_chen_yi_square_hotspot` 检查：独立热点配置与当前路网一致、纪念塔行为参数复用、
700 人路线可重复生成、刷新配额、目标与离场道路、绝对释放时刻、画像准备不丢失热点参数，
以及无旧 POI 目录情况下的完整应用初始化、停留/释放、观测输出和重置。
动态择路测试还检查从西侧、北侧和南侧道路出发时保留分配目标位置，南侧正确反向进入
R25c/R26c，不经过其他进入通道。

本轮后端 86 项、前端 39 项相关测试通过；Python/JavaScript 语法检查、修改文件 ESLint、
两仓库 diff 空白检查及前端生产构建通过。两份路网哈希与已确认的生成清单一致。

```bash
python -m unittest tests.test_chen_yi_square_hotspot tests.test_server_scenario_selection tests.test_requirement_scenario_runtime.RequirementScenarioBindingTests -v
```

此外执行既有纪念塔需求/停留/择路/指标以及前端需求、连接、路网和场景回归检查。
原道路通行模式的 SUMO CLI 结果属于此前验证，不能作为本次聚集行为的实测结果。
包含真实引擎或端口的测试保留供允许完整联调的环境使用，本轮不执行。
