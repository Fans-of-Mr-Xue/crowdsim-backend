# 人群 Agent 参数设定依据与校准方案

更新时间：2026-09-09

## 1. 文档目的

本文记录人群 Agent 属性、环境阈值和行为系数应依据什么数据设定，并区分“论文支持某种机制”和“数据已经标定某个数值”。

当前 `config/population_profiles.json` 和行为公式中的大部分数值仍是工程假设，尚未使用外滩现场数据拟合。因此，当前实验可以验证程序循环和机制是否成立，但不能把输出解释为已经复现真实外滩人群。

## 2. 参数证据等级

参数按以下等级登记，优先级从高到低：

1. `calibrated`：使用外滩同类日期、时段和场景的现场数据拟合，并经过独立数据验证。
2. `literature_prior`：来自论文实验或 SUMO 官方默认值，仅用作初始值、范围或先验分布。
3. `engineering_assumption`：为实现和机制试验临时设置，没有直接实证依据。
4. `inactive`：数据不足且无法识别，不允许影响当前决策。

论文中的研究地区、人群构成、设施和任务通常与外滩不同，因此论文数值不能自动升级为 `calibrated`。论文可以支撑变量关系和模型形式，最终数值应优先由外滩数据确定。

## 3. 属性取值依据

| 属性或参数 | 所需证据 | 推荐估计方法 | 当前状态 |
|---|---|---|---|
| `free_walking_speed` | 低密度、无事件时的匿名轨迹 | 按年龄/行动能力/时段拟合正态、对数正态或经验分布 | 工程假设；SUMO 默认值可作先验 |
| `mobility` | 同类人群低密度速度、行动辅助设备或明确行动能力分组 | 定义为相对基准速度或条件速度系数 | 工程假设；不应无条件均匀抽样 |
| `perception_radius` | 邻居距离与本人减速、转向或决策变化 | 比较不同邻域半径的样本外预测能力 | 工程假设；它是有效交互范围，不等同于视力距离 |
| `familiarity` | 到访频率、道路知识测试、出口/路线认知问卷 | 划分陌生、部分熟悉、熟悉等级，再拟合路线选择影响 | 工程假设 |
| `risk_tolerance` | 不同危险水平下继续、等待、绕行和撤离选择 | 离散选择、混合 Logit 或层级模型 | 工程假设 |
| `patience` | 排队/受阻持续时间以及何时等待或换路 | 生存分析、风险率模型或分段概率模型 | 工程假设 |
| `crowding_tolerance` | 局部密度变化与减速、绕行、退出行为 | 估计行为开始明显变化的密度区间，不先验强制成 0—1 均匀值 | 工程假设 |
| `following_tendency` | 路线信息不充分时本人、群体与周围多数人的选择 | 控制情景选择实验或真实路线选择模型 | 工程假设 |
| `group_cohesion` | 同行标注、成员距离、速度同步、等待掉队行为 | 按二人组/多人组拟合成员距离和协调概率 | 工程假设；论文仅支持机制方向 |
| `authority_compliance` | 同一风险信息由官方或非官方来源发布时的行为差异 | 控制消息内容，分别估计接收、相信和行动概率 | 工程假设 |
| `information_trust` | 官方、同伴、陌生人、社交媒体来源的采信结果 | 情景实验/问卷与实际响应联合估计 | 工程假设 |
| `stress_susceptibility` | 密度、危险强度与主观压力、皮电或心率时间序列 | 拟合刺激到压力状态的响应系数 | 工程假设 |
| `recovery_seconds` | 离开拥挤或危险后的连续恢复数据 | 拟合指数恢复或其他时间响应模型 | 工程假设 |
| `endurance` 和疲劳系数 | 长距离行走中的速度衰减、停留和恢复 | 纵向轨迹或受控步行实验 | 工程假设；没有数据时宜固定或停用 |
| 年龄、职业、国籍、语言、访问目的 | 外滩分时段访客调查或合规统计数据 | 建立按日期、时段和场景变化的条件分布 | 当前权重为工程假设 |
| POI 选择和停留时间 | POI 到访、进出和停留轨迹，以及简短问卷 | 按 POI 类型拟合选择概率和停留时间分布 | 工程假设 |
| 人群到达量与 OD | 各入口/出口分时客流和轨迹/调查 OD | 按时间片拟合到达过程和 OD 矩阵 | 场景需求，不属于固定人格属性 |

国籍、语言和职业不能在没有数据支持时直接映射为更服从、更从众、更能忍受拥挤或更快。它们可以用于描述样本和研究信息可达性；要影响决策，必须有对应的可验证实验或观测关系。

## 4. 运动、密度与 SUMO 参数

SUMO 人员规格给出的默认 `desiredMaxSpeed` 为 1.39 m/s，可作为尚无现场数据时的运动初值，而不是外滩测量结果。SUMO 还给出人员尺寸和速度离散度等默认定义。[SUMO Person specification](https://sumo.dlr.de/docs/Specification/Persons.html)

Knoblauch 等人的过街观测显示年龄组之间的速度分布存在差异，可用于说明速度应条件化，并提供初始合理范围；该研究的地域和任务并非外滩步行，因此不能直接复制为最终分布。[Knoblauch et al., 1996](https://journals.sagepub.com/doi/10.1177/0361198196153800104)

Seyfried 等人的受控实验支持“密度升高会降低速度”和使用基本图进行校准的做法。正式校准时应使用外滩道路的有效宽度、实际轨迹和分时流量重新拟合速度—密度—流量关系。[Seyfried et al., 2005](https://arxiv.org/abs/physics/0506170)

SUMO striping 模型负责 sidewalk、crossing 和 walkingarea 上的二维位置、避让和拥堵。`stripe-width`、`dawdling`、迎面预留空间、`minGap` 和 `jamtime` 等应通过轨迹、瓶颈流率、双向流和排队长度标定；官方默认值只作为初始配置。[SUMO Pedestrian Model](https://sumo.dlr.de/userdoc/Simulation/Pedestrians.html)

当前代码中的密度分级边界、压力公式系数、低速受阻阈值、风险/拥挤决策阈值和减速比例同样属于待校准参数，不能因为写在公式中就视为实测常数。

## 5. 路线、群组、信息与压力依据

Moussaïd 等人对自然行人群组的观测表明，同行社会互动会影响空间队形与整体运动。这支持显式表示群组成员、领队、等待和会合关系；不意味着当前 `group_cohesion` 的 0—1 分布已经被论文标定。[Moussaïd et al., 2010](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0010047)

Duives 和 Mahmassani 使用行人选择实验及离散选择模型研究距离、方向偏差和群体跟随对路线选择的影响。这支持用选择数据估计 `following_tendency` 和路线权重，而不是直接均匀抽样。[Duives & Mahmassani, 2012](https://journals.sagepub.com/doi/10.3141/2316-10)

出口选择实验说明出口熟悉度和邻居行为会影响选择，可用于支持 `familiarity` 和社会信息进入候选路线评分；实际系数仍需与本场景数据匹配。[Exit choice considering familiarity and neighbor behavior](https://www.sciencedirect.com/science/article/pii/S0925753516306038)

Haghani 等人的出口选择研究说明，控制情景下的选择数据可以用于估计行人在疏散中的行为权重。工程上可采用混合 Logit 或层级模型表达个体差异，并保留估计不确定性。[Haghani et al., 2017](https://www.sciencedirect.com/science/article/abs/pii/S0191261516306762)

有关拥挤环境的实验研究观察到密度、步行速度与皮电唤醒之间的联系。这支持保留动态压力状态，但不能证明当前状态方程中的具体系数；这些系数需要连续时间数据重新拟合。[The connection between stress, density, and speed in crowds](https://pmc.ncbi.nlm.nih.gov/articles/PMC10442413/)

官方指引、同伴信息和其他来源的影响必须拆成“收到—理解—相信—采取行动”几个过程，并通过保持消息内容一致的情景实验估计。不同研究场景的信任系数只能作先验，不能直接解释为外滩人群特征。[Human behaviour in response to official warning messages](https://www.sciencedirect.com/science/article/pii/S0925753516300236)

## 6. 外滩最小数据集

正式标定至少需要以下数据，并遵守隐私、伦理和数据使用要求：

- 多个工作日、周末以及有代表性活动时段的入口/出口分时计数；
- 匿名化二维轨迹、瞬时速度、道路有效宽度和瓶颈几何；
- 局部密度、排队长度、通过流率以及双向流比例；
- 可识别为同行但匿名的群组标签、成员距离和等待行为；
- 起终点、实际路线、改道点、POI 到访和停留时间；
- 简短拦访问卷：年龄段、访问目的、同行关系、熟悉度和信息渠道；
- 针对一般突发事件的受控情景选择数据：继续、减速、等待、绕行、撤离及跟随选择；
- 若要研究压力动态，采集经同意的主观量表或生理时间序列。

## 7. 标定与验证流程

1. 固定属性、状态和指标的可操作定义，避免同名变量在数据和代码中含义不同。
2. 清洗轨迹并量化位置、速度、密度和群组标注的测量误差。
3. 按人群类型、时段和场景拟合条件分布，同时保留置信区间或后验区间。
4. 使用一部分日期/时段标定，使用未参与标定的数据验证，不能在同一批数据上同时宣称拟合和验证成功。
5. 对不可直接观测的心理属性，优先估计其对行为选择的系数；只有量表与行为能够稳定映射时才生成个人 0—1 值。
6. 使用多随机种子运行，报告均值、离散程度和参数不确定性，而不是只展示一次运行。
7. 至少验证自由流速度分布、速度—密度曲线、分时流量、路线份额、排队长度、POI 停留、群组分离率和事件响应时间。
8. 验证失败时记录失败指标和适用边界，不通过任意调参隐藏误差。

## 8. 参数登记要求

后续每一个能影响仿真的参数都应保存以下元数据：

```json
{
  "parameter": "free_walking_speed",
  "status": "literature_prior",
  "source_id": "sumo-person-specification",
  "population": "SUMO default person type",
  "sample_size": null,
  "fit_method": "official_default",
  "distribution": "fixed_initial_value",
  "estimate": 1.39,
  "uncertainty": null,
  "valid_scope": "mechanism tests before Bund calibration",
  "updated_at": "2026-09-09"
}
```

现场标定后必须同时保存数据版本、代码版本、拟合脚本、参数结果和验证报告。只记录一个最终数值而没有来源、样本和适用范围，不满足可追溯要求。

## 9. 当前结论

- 当前参数足以进行程序完整性、因果循环和机制敏感性试验。
- 当前参数不足以声称已经真实复现外滩人群行为或预测实际风险数值。
- 在外滩数据到位前，应保留现有值但明确标记为 `engineering_assumption` 或 `literature_prior`。
- 对无法观测、无法识别且对结果影响明显的属性，应暂时固定、停用或只做敏感性区间，不应制造虚假的精确值。
