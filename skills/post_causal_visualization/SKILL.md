# 可视化数据组织

向前端传递三段结构化对象：观察段含 F-00 指标、样本数及候选图；干预段含各 CF 组配对效果、区间与缺失原因；机制段只展示真实事件证据。每个指标保留单位、定义版本、样本数、来源及状态。未定向边与已获干预支持的方向采用不同图例。缺失值显示原因，不填零。图表和问答文本均引用同一封存结果 ID。
