# 任务流程说明
向用户介绍事后复盘与反事实实验的完整流程，按阶段说明每一步的目标、输入、输出和可追踪信息。

向用户解释：确认目标和子问题、接入数据、质量检查、提出假设和 PC 候选、设计 F-00/CF 对照、后端校验、真实仿真、观察/干预/机制分析、报告。当前只解释流程；没有真实任务 ID、事件或结果时，不报告已完成的仿真步骤。
