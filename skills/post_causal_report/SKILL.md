# 报告结构

使用 `generate_causal_report` 获取后端报告能力；未接入时按下列结构整理 Markdown 草稿，明确“尚未持久化”。

1. 任务目标、用户子问题、数据来源、`datasetId` 与版本、事实与合成数据边界。
2. 关键节点假设、案例/因果存储来源、PC 适用性与候选图状态。
3. 锁定方案：F-00、各 CF 组、动作、控制项、种子、模型与规则版本。
4. 真实任务进度、运行 ID、失败及缺失清单。
5. 观察、干预、机制三段结果与面向子问题的回答；指标均含单位、定义版本和有效样本数。
6. 仿真模型内的干预支持、未验证方向、局限与后续验证步骤。

报告不得把草案、推算进度、PC 候选边或缺失的机制事件写成既成结果。
