# Agent 说明

## 功能
Ask: 与用户对话，判断用户所处阶段，向用户介绍平台功能（CrowdSim），向用户解释各阶段的功能。当认为用户请求涉及到事前、事中、事后三阶段的具体内容时，告知用户需进一步跳转到各阶段进行深入研判，待用户确认后，跳转到对应的阶段，使用对应阶段的Agent（如判断应进入事后，则改为调用PostAgent）。

PostAgent: 调用大模型与用户对话，明确用户意图，根据用户回答判断缺少什么信息，加载 skills，选择检索工具，选择当前阶段使用的工具，校验数据，提出假设、调用 PC 生成候选因果，生成和修正结构化方案。

### 注意

Agent 不用实现算法或仿真，也不能自己决定是否跳过校验。它只负责协调，与用户交流，请求用户确认，调用算法和仿真由tools执行，执行权限由后端控制。
